對外 API 說明文件

讓 ERP、會計軟體或自建 App 讀取訂單 / 菜單 / 會員，並以 Webhook 即時接收訂單事件
OpenAPI 3.0 規格 (JSON)

開始使用

  1. 店家負責人登入後台 → 系統設定 → API 與 Webhook → 建立 API 金鑰並勾選權限 (金鑰只顯示一次)。
  2. 呼叫時帶標頭 Authorization: Bearer kk_…；回應皆為 JSON，成功時 success 為 true。
  3. 每把金鑰每分鐘最多 120 次；要即時知道新訂單請用 Webhook，不要頻繁輪詢。
curl -H "Authorization: Bearer kk_你的金鑰" "{{ base_url }}/api/v1/orders?cursor=0&limit=50"
